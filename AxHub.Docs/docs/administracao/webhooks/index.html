Webhooks

Permite configurar webhooks para notificar sistemas externos sobre eventos do AxHub.

Como acessar​

Menu lateral → Configurações → Webhooks

CampoDescrição
URLEndereço do endpoint externo
EventoTipo de evento que dispara o webhook
MétodoPOST, PUT
HeadersCabeçalhos customizados (autenticação, etc.)
AtivoStatus do webhook
Integrações

Webhooks permitem integrar o AxHub com sistemas de terceiros como ERPs, DETRAN e órgãos de trânsito.
