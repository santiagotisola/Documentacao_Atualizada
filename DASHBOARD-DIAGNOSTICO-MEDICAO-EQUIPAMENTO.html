Checklist de Validação

Use esta lista para validar manualmente se todos os requisitos estão atendidos:

📋 1. Equipamento: Verificar se existe no TBEquipamentos
✅ 2. Status Equipamento: Status = Ativo (1)
🛣️ 3. Faixas: Possui faixas cadastradas no TBFaixas
✅ 4. Status Faixas: Todas as faixas estão Ativas (1)
📄 5. Contrato: Existe contrato cadastrado no TBContratos
✅ 6. Status Contrato: Contrato está Ativo (1)
📅 7. Vigência Contrato: DataInicio ≤ Hoje ≤ DataFim
🔗 8. Vínculo: Equipamento vinculado ao contrato (TBContratosEquipamentos)
🔴 9. RECURSOS: Existe 1 recurso para CADA faixa no TBRecursos
💰 10. Valor Previsto: ValorPrevisto > 0
📊 11. BDI: BDI ≥ 0 (pode ser zero)
✅ 12. Status Recurso: Status = Ativo (1)
📅 13. Vigência Recurso: DataInicio ≤ DataMedição ≤ DataFim
🚗 14. Passagens: Existem registros no TBPassagens para o período
⚠️
Itens Críticos (9-13): Se qualquer um destes itens falhar, os valores aparecerão como R$ 0,00 no relatório. Os recursos (TBRecursos) são o ponto mais crítico!

Solução: Cadastrar Recursos

✅
Causa mais comum: RECURSOS NÃO CADASTRADOS na tabela TBRecursos para as faixas do equipamento.

📝 Passo a Passo para Cadastrar Recurso:

  1. Acesse: Medição → Recursos → Novo Recurso
  2. Equipamento: Selecione -
  3. Faixa: Selecione a Faixa 1
  4. Contrato: Selecione o contrato correspondente
  5. Descrição: "Recurso Medição - - Faixa 1"
  6. Valor Previsto: R$ 15.000,00 (ou valor contratual)
  7. BDI (%): 25,00 (ou percentual contratual)
  8. Data Início: Data início do contrato
  9. Data Fim: Data fim do contrato
  10. Status: Ativo
  11. Salvar
  12. 🔄 REPETIR para a Faixa 2
⚠️
Importante: Você DEVE cadastrar 1 recurso para CADA faixa. Se o equipamento tem 2 faixas, precisa de 2 recursos. Não cadastre 1 recurso só para o equipamento inteiro.

🔍 Validar a Correção:

  1. Acesse: -/medicao/relatoriomedicaoequipamento
  2. Selecione o Órgão/Contrato
  3. Selecione o Período (ex: Maio/2026)
  4. Selecione o Equipamento: -
  5. Clique em Gerar Relatório
  6. ✅ Verifique se os valores apareceram:
    • VALOR PREVISTO: R$ 15.000,00 (por faixa)
    • BDI: 25,00%
    • TOTAL: R$ 18.750,00 (por faixa)
