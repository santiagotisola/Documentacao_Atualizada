# Categorias de Veículos

Permite cadastrar e gerenciar as categorias de veículos.

![Lista de Categorias](../img/Veículos%20-%20categoia%20de%20veículos.png)

## Como acessar

**Menu lateral** → Veículos → **Categorias de Veículos**

## Cadastro

![Cadastro de Categoria](../img/Veículos%20-%20categoia%20de%20veículos%20-%20cadastro.png)

| Campo | Descrição |
|-------|-----------|
| **Código** | Código identificador |
| **Descrição** | Nome da categoria |
| **Ativo** | Status do registro |
