# Regras de Exceção

As exceções permitem definir regras para que determinadas infrações sejam automaticamente descartadas com base em critérios como placa do veículo, horário, faixa, classificação do veículo ou enquadramento.

## Como acessar

**Menu lateral** → Exceções

## Tipos de filtro

| Filtro | Descrição |
|--------|-----------|
| **Placas** | Exceção para placas específicas (ex: veículos oficiais) |
| **Horários** | Exceção por dia da semana e faixa de horário |
| **Faixas** | Exceção para faixas de trânsito específicas |
| **Classificações** | Exceção por classificação do veículo |
| **Enquadramentos** | Exceção por tipo de infração/enquadramento legal |
| **Datas** | Exceção para períodos específicos (ex: feriados, eventos) |

## Funcionalidades

- Criar regras de exceção com múltiplos filtros combinados
- Definir motivo de descarte automático
- Configurar período de vigência da exceção
- Ativar/desativar exceções sem excluí-las
