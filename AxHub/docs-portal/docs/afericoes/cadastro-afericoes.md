# Aferições

O módulo de aferições permite registrar e controlar as calibrações dos equipamentos conforme exigências do INMETRO. Cada aferição registra dados do lacre, número INMETRO, série do equipamento e laudos.

## Como acessar

**Menu lateral** → Equipamentos → **Aferições**

## Funcionalidades

- Registrar aferições (iniciais, periódicas e extraordinárias)
- Controlar datas de vencimento dos certificados
- Gerenciar lacres (número, status, data de rompimento)
- Vincular aferições às faixas cobertas
- Anexar documentos e laudos de aferição

## Campos principais

| Campo | Descrição |
|-------|-----------|
| **Data Aferição** | Data em que a aferição foi realizada |
| **Data Vencimento** | Data de vencimento do certificado |
| **Número Lacre** | Número do lacre físico do equipamento |
| **Número INMETRO** | Número do certificado INMETRO |
| **Número Série** | Número de série do equipamento aferido |
| **Número Laudo** | Número do laudo técnico |
| **Tipo Aferição** | Inicial, periódica ou extraordinária |
| **Status Lacre** | Status atual do lacre (íntegro, rompido) |
