# AxHub - Manual do Usuário

Bem-vindo ao manual do usuário do **AxHub**, o sistema de gestão de equipamentos de trânsito da Axion Tecnologia.

## O que é o AxHub?

O AxHub é uma plataforma completa para **gestão de equipamentos de fiscalização de trânsito**, integrando radares metrológicos e não metrológicos, câmeras OCR e balanças de pesagem. O sistema cobre todo o ciclo de vida da fiscalização eletrônica de trânsito:

- **Cadastro e gestão de equipamentos** — fabricantes, modelos, tipos e grupos de equipamentos
- **Operações de campo** — implantação de equipamentos em faixas de trânsito com controle de velocidades regulamentadas
- **Recepção de dados** — importação automática de passagens e imagens dos equipamentos
- **Processamento de infrações** — detecção automática de infrações de velocidade, avanço de sinal, faixa exclusiva e pesagem
- **Triagem e auditoria** — fluxo de revisão humana para validação ou descarte de infrações
- **Exportação para órgãos** — envio de infrações validadas para os órgãos autuadores (DETRAN, DER, PRF, etc.)
- **Monitoramento em tempo real** — acompanhamento do status online/offline dos equipamentos
- **Medições contratuais** — cálculo de índices de performance e horas de operação para faturamento
- **Distribuição de dados** — envio de informações de tráfego via webhook para sistemas integrados
- **Relatórios** — dashboards Power BI e relatórios operacionais

## Como usar este manual

Use o **menu lateral** para navegar entre os módulos do sistema. Cada seção contém:

- **Descrição da funcionalidade** — o que a tela faz e quando utilizá-la
- **Como acessar** — caminho no menu do sistema
- **Campos e descrições** — detalhamento de cada campo da tela
- **Passo a passo** — instruções para as operações principais
- **Regras importantes** — validações e comportamentos do sistema

:::tip Dica
Em cada tela do AxHub, você encontrará um link de ajuda que o direcionará diretamente para a documentação daquela funcionalidade.
:::

## Estrutura do Sistema

O AxHub é organizado nos seguintes módulos:

| Módulo | Descrição |
|--------|-----------|
| **Primeiros Passos** | Login, navegação e dashboard |
| **Cadastros Básicos** | Fabricantes, tipos, modelos, grupos e equipamentos |
| **Operações** | Implantação de equipamentos nas faixas de trânsito |
| **Aferições** | Calibrações e certificados INMETRO |
| **Processamento** | Importação de passagens e dados dos equipamentos |
| **Triagem e Auditoria** | Revisão e validação de infrações |
| **Infrações** | Consulta e exportação de infrações |
| **Pesagem** | Postos e tickets de pesagem veicular |
| **Monitoramento** | Status dos equipamentos em tempo real |
| **Exceções** | Regras de exceção para infrações |
| **Medições** | Medições contratuais e índices de performance |
| **Contratos** | Gestão de contratos e ajustes |
| **Relatórios** | Dashboards e relatórios operacionais |
| **Webhooks** | Integração com sistemas externos |
| **Administração** | Usuários, perfis, permissões e configurações |
