# Faixas

Permite configurar as faixas de monitoramento de cada operação.

![Lista de Faixas](../img/Operações%20-%20Faixas.png)

## Como acessar

**Menu lateral** → Operações → **Faixas**

## Cadastro de faixa

![Cadastro de Faixa](../img/Operações%20-%20Faixas%20-%20cadatro.png)

| Campo | Descrição |
|-------|-----------|
| **Operação** | Operação vinculada |
| **Número da Faixa** | Identificador da faixa |
| **Sentido** | Sentido de tráfego monitorado |
| **Tipo** | Faixa de rolamento, acostamento, etc. |
