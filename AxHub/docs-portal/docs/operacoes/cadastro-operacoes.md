# Cadastro de Operações

As operações representam a implantação de equipamentos em faixas de trânsito para fiscalização. Cada operação vincula um equipamento a uma ou mais faixas com velocidades regulamentadas.

## Como acessar

**Menu lateral** → Operações → **Operações**

## Funcionalidades

- Vincular equipamento a faixas de trânsito
- Definir velocidades regulamentadas por faixa
- Configurar período de operação (data início e fim)
- Definir órgão autuador responsável
- Registrar dados de homologação
- Controlar interrupções de operação
- Anexar documentos à operação

## Campos principais

| Campo | Descrição |
|-------|-----------|
| **Equipamento** | Equipamento vinculado à operação |
| **Data Instalação** | Data de instalação do equipamento no local |
| **Data Início** | Início da operação de fiscalização |
| **Data Fim** | Fim da operação (vazio = operação contínua) |
| **Órgão Autuador** | Órgão responsável pela autuação (DETRAN, DER, etc.) |
| **Tarja** | Template de sobreposição de informações nas imagens |
