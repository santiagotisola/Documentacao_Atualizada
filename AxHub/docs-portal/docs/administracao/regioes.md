# Regiões

Permite cadastrar e gerenciar as regiões geográficas utilizadas no agrupamento de operações.

## Como acessar

**Menu lateral** → Configurações → **Regiões**

| Campo | Descrição |
|-------|-----------|
| **Nome** | Nome da região |
| **UF** | Estado vinculado |
| **Descrição** | Detalhamento |
| **Ativo** | Status do registro |
