# Usuários

O módulo de administração de usuários permite gerenciar as contas de acesso ao AxHub, definindo perfis, permissões e restrições de acesso.

## Como acessar

**Menu lateral** → Configurações → **Usuários**

## Funcionalidades

- Cadastrar e gerenciar usuários do sistema
- Atribuir perfis de acesso (Administrador, Analista, Auditor, etc.)
- Definir papéis operacionais (Analista de Triagem, Auditor de Válidas, Auditor de Descartadas, Supervisor)
- Restringir acesso por grupo de equipamentos
- Configurar restrições por IP
- Definir horários de acesso permitidos
- Bloquear acesso por período
- Habilitar autenticação de dois fatores (2FA)

## Campos principais

| Campo | Descrição |
|-------|-----------|
| **Nome** | Nome completo do usuário |
| **Username** | Nome de usuário para login |
| **E-mail** | E-mail do usuário (usado para recuperação de senha) |
| **Telefone** | Telefone do usuário |
| **Código Agente** | Código do agente (para identificação em triagem/auditoria) |
| **Admin** | Se o usuário é administrador do sistema |
| **2FA** | Se a autenticação de dois fatores está habilitada |

## Perfis de acesso

Os perfis de acesso definem quais funcionalidades cada usuário pode acessar. Cada perfil possui um conjunto de permissões que pode ser personalizado.
