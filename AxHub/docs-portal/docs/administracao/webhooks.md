# Webhooks

Permite configurar webhooks para notificar sistemas externos sobre eventos do AxHub.

![Webhooks](../img/Configurações%20-%20Webhooks.png)

## Como acessar

**Menu lateral** → Administração → **Webhooks**

| Campo | Descrição |
|-------|-----------|
| **URL** | Endereço do endpoint externo |
| **Evento** | Tipo de evento que dispara o webhook |
| **Método** | POST, PUT |
| **Headers** | Cabeçalhos customizados (autenticação, etc.) |
| **Ativo** | Status do webhook |

:::info Integrações
Webhooks permitem integrar o AxHub com sistemas de terceiros como ERPs, DETRAN e órgãos de trânsito.
:::
