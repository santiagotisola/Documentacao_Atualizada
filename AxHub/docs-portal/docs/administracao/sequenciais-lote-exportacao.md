# Sequenciais de Lote de Exportação

Permite configurar e monitorar os sequenciais dos lotes de exportação de Infrações

## Como acessar

**Menu lateral** → Configurações → **Sequenciais de Lote de Exportação**

| Campo | Descrição |
|-------|-----------|
| **Órgão** | Órgão destinatário |
| **Sequencial Atual** | Último lote exportado |
| **Formato** | Layout do arquivo de exportação |
| **Status** | Ativo, Esgotado |
