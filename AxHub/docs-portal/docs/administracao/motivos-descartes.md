# Motivos de Descarte

Permite cadastrar os motivos que justificam o descarte de infrações durante a triagem.

## Como acessar

**Menu lateral** → Administração → **Motivos de Descarte**

| Campo | Descrição |
|-------|-----------|
| **Código** | Código identificador |
| **Descrição** | Descrição do motivo (ex: Imagem ilegível, Placa não identificada) |
| **Ativo** | Status do registro |
