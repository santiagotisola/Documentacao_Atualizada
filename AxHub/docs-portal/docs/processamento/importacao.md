# Importação

O módulo de importação gerencia a recepção de dados (passagens e imagens) enviados pelos equipamentos de campo ao AxHub.

## Como acessar

**Menu lateral** → Importação

## Funcionalidades

- Visualizar lotes de importação recebidos
- Acompanhar status de cada lote (em processamento, concluído, erro)
- Consultar erros de importação
- Filtrar por equipamento, fabricante e período

## Status dos lotes

| Status | Descrição |
|--------|-----------|
| **Em processamento** | Lote sendo processado pelo sistema |
| **Concluído** | Lote importado com sucesso |
| **Erro** | Falha na importação — verificar detalhes do erro |
