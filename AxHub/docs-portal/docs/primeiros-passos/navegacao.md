# Navegação

O AxHub possui uma interface organizada com menu lateral, barra superior e área de conteúdo principal.

## Menu lateral

O menu lateral esquerdo contém ícones que dão acesso a todos os módulos do sistema:

| Ícone | Módulo | Descrição |
|:-----:|--------|-----------|
| Dashboard | **Dashboard** | Painel principal com visão geral do sistema |
| Triagem | **Triagem** | Módulo de triagem de infrações |
| Monitoramento | **Monitoramento** | Monitoramento em tempo real dos equipamentos |
| Importação | **Importação** | Importação de lotes de dados dos equipamentos |
| Equipamentos | **Equipamentos** | Cadastro e gestão dos equipamentos de trânsito |
| Passagens | **Passagens** | Consulta de passagens de veículos detectadas |
| Operações | **Operações** | Gestão das operações de campo |
| Medições | **Medições** | Medições contratuais e índices de performance |
| Relatórios | **Relatórios** | Relatórios operacionais e dashboards |
| Pesagem | **Pesagem** | Módulo de pesagem veicular |
| Exceções | **Exceções** | Regras de exceção para infrações |
| Configurações | **Configurações** | Configurações gerais do sistema |

:::tip Dica
Passe o mouse sobre os ícones do menu para ver o nome do módulo.
:::

## Barra superior

A barra superior contém:

- **Título da página** — indica em qual tela você está
- **Notificações** (ícone de sino) — alertas e notificações do sistema
- **Menu de aplicações** (ícone de grade) — acesso rápido a outras aplicações
- **Usuário logado** — nome do usuário atual e opções de perfil/logout

## Padrões de tela

O AxHub segue padrões consistentes em todas as telas:

### Telas de listagem
- Botão **+ Novo** para criar um registro
- Botão **Excel** para exportar dados
- Campo **Pesquisa** para busca rápida
- Colunas **ordenáveis** (clique no cabeçalho) e **filtráveis** (ícone de funil)
- Botões de **Editar** e **Excluir** em cada linha
- **Paginação** no rodapé com controle de itens por página

### Telas de cadastro
- Botão **Voltar** (seta para esquerda) para retornar à listagem
- Botão **Salvar** para gravar as alterações
- Campos obrigatórios marcados com **asterisco vermelho** (*)

## Rodapé

Todas as telas exibem no rodapé:
- **Copyright** da Axion Tecnologia
- **Versão** do sistema (ex: AxHub v.1.1.0)
