# Navegação

O AxHub possui uma interface intuitiva com menu lateral para acesso rápido a todos os módulos.

![Mapa Online](../img/mapa%20online.png)

## Estrutura do menu

O menu lateral é organizado nos seguintes grupos:

| Grupo | Módulos |
|-------|---------|
| **Infrações** | Triagem, Auditoria, Consulta, Exceções, Exportação, Descartadas |
| **Cronotacógrafo** | Triagem, Consulta |
| **Balança** | Postos, Motivos, Tickets, Liberação, Reclassificação |
| **Operações** | Operações, Faixas, Aferições, Monitoramento, Eventos, Consulta de Placas |
| **Veículos** | Tipos, Espécies, Categorias, Classificações, Cores, Marcas, Modelos, Municípios |
| **Equipamentos** | Equipamentos, Tipos, Grupos, Fabricantes, Modelos |
| **Medição** | Contratos, Índices, Recursos, Interrupções, Medições |
| **Relatórios** | Infrações, Passagens, Discrepâncias, Eventos, Falhas, Fluxo, Power BI |
| **Controle de Acesso** | Usuários, Perfis, Permissões, IP, Logs |
| **Administração** | Configurações, Arcos, Enquadramentos, Webhooks, Power BI |

## Atalhos

- **Barra superior** — acesso rápido ao dashboard e notificações
- **Breadcrumb** — navegação hierárquica entre páginas
- **Pesquisa** — busca rápida por funcionalidade
