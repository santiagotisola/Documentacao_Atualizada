# Dashboard

O Dashboard e a tela inicial do AxHub apos o login. Apresenta indicadores, mapa de equipamentos e alertas.

## Como acessar

O Dashboard e exibido automaticamente apos o Login. Clique no logo do AxHub para retornar.
