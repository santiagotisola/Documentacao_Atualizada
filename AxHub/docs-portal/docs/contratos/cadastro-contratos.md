# Contratos

O módulo de contratos permite gerenciar os contratos de prestação de serviços entre a operadora dos equipamentos e os órgãos de trânsito.

## Como acessar

**Menu lateral** → Configurações → **Contratos**

## Funcionalidades

- Cadastrar contratos com período de vigência
- Definir percentual de BDI (Bonificação e Despesas Indiretas)
- Configurar valores por faixa de trânsito
- Registrar ajustes contratuais

## Campos principais

| Campo | Descrição |
|-------|-----------|
| **Nome** | Nome identificador do contrato |
| **Número** | Número oficial do contrato |
| **Data Início** | Início da vigência |
| **Data Fim** | Fim da vigência |
| **BDI (%)** | Percentual de Bonificação e Despesas Indiretas |
| **Descrição** | Descrição detalhada do contrato |
