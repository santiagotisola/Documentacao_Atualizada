## Listagem

| Coluna | Descricao |
|--------|-----------|
| Data/Hora | Momento da pesagem |
| Placa | Placa do veiculo pesado |
| PBT | Peso Bruto Total registrado |
| PBT Limite | Limite legal de peso para o tipo de veiculo |
| Excesso | Peso acima do limite se houver |
| Status | Regular ou Excesso ou Descartado |
