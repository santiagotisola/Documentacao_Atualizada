# Use Infração (com acento) de Transito

## Definicao

Ato de inobservancia a qualquer preceito da legislacao de transito, as normas emanadas do código de Transito Brasileiro, do CONTRAN e dos orgaos executivos de transito.

## Base Legal

Art. 161 do CTB (Lei 9.503/1997): Constitui Use Infração (com acento) de transito a inobservancia de qualquer preceito deste código da legislacao complementar ou das resolucoes do CONTRAN. As infracoes sao classificadas em: leve, media, grave e gravissima (Art. 258 CTB).

## Uso no Sistema AxHub

O sistema AxHub captura automaticamente evidencias de infracoes atraves de Equipamentos metrologicos (radares, cameras OCR, balancas). Cada registro passa pelo fluxo: **Captura - Triagem - Auditoria - Exportacao**.
