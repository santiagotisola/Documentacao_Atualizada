# Autuacao

## Definicao

Ato administrativo pelo qual o agente de transito ou equipamento eletronico registra formalmente a ocorrencia de uma infracao. A autuacao gera o Auto de Infracao de Transito (AIT).

## Base Legal

Art. 280 do CTB: Ocorrendo infracao prevista na legislacao de transito, lavrar-se-a auto de infracao. A Resolucao CONTRAN 619/2016 regulamenta o uso de equipamentos eletronicos para autuacao automatica.

## Uso no Sistema AxHub

No AxHub, a autuacao ocorre ao final do fluxo de triagem, quando o operador confirma a validade da infracao. O sistema gera o registro no formato exigido pelo orgao autuador. As **Formas de Autuacao** sao configuradas em Administracao.
