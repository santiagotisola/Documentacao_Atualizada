# Lote de Exportacao

## Definicao

Conjunto agrupado de infracoes processadas e validadas, formatado para envio ao orgao autuador (DETRAN, DER, Prefeitura) atraves de integracao sistemica.

## Base Legal

Resolucao CONTRAN 619/2016, que define o formato e conteudo obrigatorio dos registros de infracao para integracao entre sistemas.

## Uso no Sistema AxHub

No modulo **Infracoes - Exportacao**, o sistema agrupa as infracoes auditadas em lotes conforme o layout definido em **Administracao - Layouts de Arquivos**. Os sequenciais sao controlados em **Sequenciais de Lote de Exportacao**.
