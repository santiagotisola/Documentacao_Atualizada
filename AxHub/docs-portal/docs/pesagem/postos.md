# Postos de Pesagem

Os postos de pesagem são locais de fiscalização de peso de veículos de carga, integrados ao AxHub para registro de tickets e controle de sobrepeso.

## Como acessar

**Menu lateral** → Pesagem → **Postos**

## Funcionalidades

- Cadastrar postos de pesagem com localização geográfica
- Controlar sessões de funcionamento (abertura/fechamento)
- Vincular operações e equipamentos ao posto
- Gerenciar usuários autorizados por posto
