# Reclassificar

Permite reclassificar veículos que foram pesados com classificação incorreta.

![Reclassificar](../img/Balança%20-%20Reclassificar.png)

## Como acessar

**Menu lateral** → Balança → **Reclassificar**

| Campo | Descrição |
|-------|-----------|
| **Ticket** | Ticket da pesagem original |
| **Classificação Atual** | Tipo de veículo registrado |
| **Nova Classificação** | Classificação correta |
| **Motivo** | Justificativa da reclassificação |
