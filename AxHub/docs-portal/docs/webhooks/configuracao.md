# Webhooks

O AxHub distribui informações de tráfego e eventos para sistemas externos via webhooks. Configure endpoints para receber notificações automáticas quando eventos específicos ocorrem no sistema.

## Como acessar

**Menu lateral** → Configurações → **Webhooks**

## Funcionalidades

- Cadastrar URLs de destino para recebimento de eventos
- Selecionar tipos de eventos a serem notificados
- Vincular webhooks a operações específicas
- Ativar/desativar webhooks individualmente
- Configurar modo transacional

## Campos principais

| Campo | Descrição |
|-------|-----------|
| **Nome** | Nome identificador do webhook |
| **URL** | Endereço do endpoint que receberá as notificações |
| **Tipo de Evento** | Tipo de evento que dispara a notificação |
| **Ativo** | Se o webhook está ativo ou desativado |
| **Transacional** | Se o envio deve aguardar confirmação do destinatário |
