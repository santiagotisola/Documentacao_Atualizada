AxHub — Guia de Criação de Usuário e Permissões

Axion Tecnologia • Sistema de Gestão de Equipamentos de Trânsito

Este guia descreve o passo a passo para criar um novo usuário no sistema AxHub e configurar suas permissões de acesso.

1 Criar um Perfil de Acesso

Antes de criar o usuário, verifique se já existe um perfil adequado. Caso contrário, crie um novo:

  1. No menu lateral, acesse Controle de Acesso → Perfis de Acesso
  2. Clique em Novo
  3. Preencha os campos conforme a tabela abaixo
  4. Clique em Salvar
CampoO que informar
Nome do PerfilIdentificação do perfil (ex: Operador, Analista, Auditor, Administrador)
DescriçãoBreve descrição das responsabilidades deste perfil

2 Configurar Permissões do Perfil

  1. No menu lateral, acesse Controle de Acesso → Permissões de Acesso
  2. Selecione o perfil que deseja configurar
  3. Para cada módulo do sistema, marque as permissões desejadas
  4. Clique em Salvar
PermissãoO que permite
VisualizarConsultar dados e relatórios do módulo
CriarInserir novos registros
EditarAlterar registros existentes
ExcluirRemover registros
Dica: Para um usuário que apenas consulta dados, marque somente "Visualizar". Para operadores de triagem, marque "Visualizar" + "Criar" + "Editar" nos módulos de Infrações e Operações.

3 Criar o Usuário

  1. No menu lateral, acesse Controle de Acesso → Usuários
  2. Clique em Novo
  3. Preencha os campos conforme a tabela abaixo
  4. Defina uma senha temporária
  5. Clique em Salvar
CampoO que informar
NomeNome completo do usuário
LoginNome que será usado para entrar no sistema
E-mailE-mail válido (usado para recuperação de senha)
Perfil de AcessoSelecione o perfil criado no Passo 1
AtivoMarque como Sim

4 Primeiro Acesso do Usuário

Repasse ao novo usuário as seguintes informações:

InformaçãoDetalhe
Endereço do sistemaURL de acesso ao AxHub
LoginConforme definido no cadastro
Senha temporáriaDefinida no momento da criação
Importante: Recomende ao usuário alterar a senha no primeiro acesso por questões de segurança.
Resumo do fluxo:

Perfis de Acesso → criar perfil → Permissões → configurar → Usuários → criar usuário → atribuir perfil
