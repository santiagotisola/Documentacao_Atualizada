```json
{
  "label": "Nome do Módulo",
  "position": 3,
  "collapsible": true,
  "collapsed": true

```

**Exceções:**
- `primeiros-passos`: `"collapsed": false` (aberto por padrão)
- `glossario`: `"collapsed": false`, última posição, com link gerado:

```json

  "label": "Glossário Técnico",
  "position": 13,
  "collapsed": false,
  "link": {
    "type": "generated-index",
    "description": "Termos técnicos utilizados no sistema."
  }
}
```

### 7.2 intro.md (página raiz)

```markdown
---
sidebar_position: 1
slug: /
title: Visão Geral
---

# {NomeProjeto} — Manual do Usuário

Bem-vindo ao manual do **{NomeProjeto}**, {descrição} da Axion Tecnologia.

## Estrutura do Sistema

| # | Módulo | Descrição |
|---|--------|-----------|
| 1 | [Primeiros Passos](./primeiros-passos/login) | Login, navegação e dashboard |
| 2 | [{Módulo}](./{slug}/{pagina}) | {Descrição} |

Use o **menu lateral** para navegar. Cada seção contém:
- **Como acessar** — caminho no menu do sistema
- **Campos exibidos** — detalhamento de cada campo
- **Filtros disponíveis** — opções de pesquisa
```

## 9. GITHUB ACTIONS (deploy)

```yaml
name: Deploy {NomeProjeto} Docs to GitHub Pages

on:
  push:
    branches: [main]
    paths: ['{NomeProjeto}/docs-portal/**']

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages-{nome-lower}"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: {NomeProjeto}/docs-portal
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
          cache-dependency-path: {NomeProjeto}/docs-portal/package-lock.json
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: {NomeProjeto}/docs-portal/build

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
