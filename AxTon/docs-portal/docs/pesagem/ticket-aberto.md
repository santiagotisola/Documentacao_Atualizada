# Tickets em Aberto

![Tela de Tickets de Pesagens](../img/Tickets%20de%20pesagens.png)

Tickets em aberto são registros de pesagem que ainda não foram finalizados. Podem estar aguardando complementação de dados, segunda pesagem ou liberação.

## Como acessar

**Menu lateral** → **Tickets de Pesagens**

![Emitir Ticket de Pesagem](../img/Tickets%20de%20pesagens%20-%20emitir%20ticket.png)

## Listagem

### Colunas

| Coluna | Descrição |
|--------|-----------|
| **Nº Ticket** | Número sequencial do ticket |
| **Placa** | Placa do veículo pesado |
| **Data/Hora** | Data e hora do registro |
| **Peso Bruto** | Peso total registrado (kg) |
| **Posto** | Posto onde a pesagem foi realizada |
| **Status** | Pendente, Aguardando 2ª pesagem |

### Ações disponíveis

| Ação | Descrição |
|------|-----------|
| **Visualizar** | Abrir detalhes completos do ticket |
| **Finalizar** | Completar o processo de pesagem |
| **Imprimir** | Gerar comprovante do ticket |

### Passo a passo — Finalizar Ticket

1. No menu lateral, clique em **Tickets de Pesagens**
2. Localize o ticket desejado
3. Clique em **Visualizar**
4. Verifique os dados do veículo e pesos
5. Clique em **Finalizar**
6. Confirme a operação
