# Triagem de Infrações

![Tela de Sequenciais de Infração](../img/sequenciais%20de%20infracao.png)

A triagem é o processo de análise humana das infrações detectadas automaticamente nas pesagens. O operador valida os dados, verifica as imagens e decide se a infração deve ser processada ou descartada.

## Como acessar

**Menu lateral** → Infrações → **Triagem**

## Elementos da Tela

### Painel de Imagens (esquerda)
- Imagens capturadas do veículo
- Dados da passagem (placa, peso, data/hora)
- Classificação do veículo

### Painel de Dados (direita)
- Dados do veículo para preenchimento/confirmação
- Peso registrado e PBT permitido
- Cálculo do excesso

## Ações na Triagem

| Ação | Descrição |
|------|-----------|
| **Processar** | Aprova a infração — segue para auditoria |
| **Descartar** | Rejeita a infração — obrigatório informar motivo |
| **Avaliar Depois** | Reserva para análise posterior |

### Passo a passo — Triar Infração

1. Acesse Infrações → Triagem
2. O sistema exibe a próxima infração pendente
3. Analise as imagens: placa legível e dados válidos?
4. Confirme/corrija os dados do veículo
5. Verifique o peso registrado e o excesso calculado
6. Infração válida: clique em **Processar**
7. Infração inválida: selecione o Motivo e clique em **Descartar**
8. Precisa mais tempo: clique em **Avaliar Depois**

:::warning Atenção
Infrações descartadas sem motivo adequado podem gerar inconsistências nos relatórios de produtividade.
:::
