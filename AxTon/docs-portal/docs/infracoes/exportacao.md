# Exportação de Infrações

![Tela de Exportação de Infrações](../img/Exportacao%20de%20infracoes.png)

A exportação envia as infrações aprovadas na auditoria para o órgão autuador em lotes. Cada lote contém os dados, imagens e assinatura digital.

## Como acessar

**Menu lateral** → **Exportação**

![Dados Exportados](../img/Exportacao%20de%20infracoes.-%20dados%20exportados.png)

![Nova Exportação](../img/Exportacao%20de%20infracoes.-%20nova.png)

## Listagem de Lotes

### Colunas

| Coluna | Descrição |
|--------|-----------|
| **Nº Lote** | Número do lote |
| **Data** | Data de geração |
| **Qtd Infrações** | Quantidade de infrações no lote |
| **Status** | Pendente, Enviado, Aceito, Erro |

### Status dos Lotes

| Status | Descrição |
|--------|-----------|
| **Pendente** | Lote gerado, aguardando envio |
| **Enviado** | Lote transmitido ao órgão |
| **Aceito** | Lote aceito pelo órgão autuador |
| **Erro** | Lote com erros — verificar detalhes |

### Passo a passo — Exportar Lote

1. No menu lateral, clique em **Exportação**
2. Clique em **Gerar Novo Lote**
3. Defina o período e filtros
4. Revise a quantidade de infrações
5. Clique em **Gerar**
6. Após gerado, clique em **Enviar**
7. Acompanhe o status até "Aceito"

:::warning Erros comuns
- **Código do município divergente**: Verifique o cadastro de faixas
- **Imagens ausentes**: Verifique o processamento de imagens
- **Dados incompletos**: Retorne para triagem e complete os dados
:::
