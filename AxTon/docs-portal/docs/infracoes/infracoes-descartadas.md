# Infrações Descartadas

![Sequenciais de Infração — Novo](../img/sequenciais%20de%20infracao%20-%20movo.png)

Consulta de infrações que foram descartadas durante o processo de triagem, com possibilidade de reabrir para reanálise.

## Como acessar

**Menu lateral** → Infrações → **Descartadas**

## Listagem

### Colunas

| Coluna | Descrição |
|--------|-----------|
| **ID** | Identificador da infração |
| **Placa** | Placa do veículo |
| **Data** | Data da infração |
| **Motivo Descarte** | Razão informada pelo triador |
| **Triador** | Operador que descartou |
| **Ações** | Visualizar, Reabrir |

### Passo a passo — Reabrir Infração

1. Acesse Infrações → Descartadas
2. Localize a infração
3. Clique em **Visualizar** para conferir
4. Se necessário, clique em **Reabrir**
5. A infração retorna para a fila de Triagem
