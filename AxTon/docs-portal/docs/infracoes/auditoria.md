# Auditoria de Infrações

![Sequencial de Infração — Dados](../img/sequencial%20de%20infracao%20dados.png)

A auditoria é a etapa de revisão das infrações já processadas na triagem. Um segundo operador valida os dados antes do envio ao órgão autuador.

## Como acessar

**Menu lateral** → Infrações → **Auditoria**

## Listagem

### Colunas

| Coluna | Descrição |
|--------|-----------|
| **ID** | Identificador da infração |
| **Placa** | Placa do veículo |
| **Data** | Data da infração |
| **Peso** | Peso bruto registrado |
| **Excesso** | Peso excedente |
| **Triador** | Operador que processou |
| **Status** | Pendente, Aprovada, Reprovada |

### Passo a passo

1. Acesse Infrações → Auditoria
2. Selecione a infração pendente
3. Revise imagens e dados
4. Aprovada: clique em **Aprovar**
5. Reprovada: clique em **Reprovar** com justificativa
