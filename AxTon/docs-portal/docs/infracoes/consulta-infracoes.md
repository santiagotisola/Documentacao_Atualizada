# Consulta de Infrações

![Sequencial de Infração](../img/sequencial%20de%20infracao.png)

Permite pesquisar e consultar todas as infrações registradas no sistema, independente do status.

## Como acessar

**Menu lateral** → Infrações → **Consulta**

## Filtros de Pesquisa

| Filtro | Descrição |
|--------|-----------|
| **Período** | Data inicial e final |
| **Placa** | Placa do veículo |
| **Status** | Pendente, Processada, Descartada, Exportada |
| **Posto** | Posto de pesagem |

## Resultados

### Colunas

| Coluna | Descrição |
|--------|-----------|
| **ID** | Identificador único |
| **Placa** | Placa do veículo |
| **Data/Hora** | Momento da infração |
| **Posto** | Local da pesagem |
| **Peso Bruto** | Peso total |
| **Excesso** | Peso excedente |
| **Status** | Estado atual da infração |
| **Ações** | Visualizar detalhes |

### Passo a passo

1. Acesse Infrações → Consulta
2. Defina os filtros desejados
3. Clique em **Pesquisar**
4. Clique sobre uma infração para ver detalhes completos
