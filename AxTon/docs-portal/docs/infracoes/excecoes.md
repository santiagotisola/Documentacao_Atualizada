# Exceções

![Sequencial de Exportação](../img/sequencial%20de%20exportacao.png)

As exceções definem regras para dispensar automaticamente determinados veículos ou situações da autuação por excesso de peso.

## Como acessar

**Menu lateral** → Infrações → **Exceções**

## Tipos de Exceção

| Tipo | Descrição |
|------|-----------|
| **Por Placa** | Veículos específicos dispensados |
| **Por Classificação** | Tipos de veículo isentos |
| **Por Horário** | Faixas horárias com tolerância |
| **Por Período** | Datas específicas (eventos, obras) |

### Campos do Cadastro

| Campo | Obrigatório | Descrição |
|-------|:-----------:|-----------|
| **Tipo** | Sim | Categoria da exceção |
| **Valor** | Sim | Placa, classificação ou período |
| **Motivo** | Sim | Justificativa da exceção |
| **Validade** | Não | Data de expiração |

### Passo a passo

1. Acesse Infrações → Exceções
2. Clique em **+ Nova Exceção**
3. Selecione o Tipo
4. Informe o Valor (placa, classificação etc.)
5. Descreva o Motivo
6. Defina a Validade, se aplicável
7. Clique em **Salvar**
