# AxTon — Manual do Usuário

![Menu Principal do AxTon](./img/Menu%20principal%20-%20Axton.png)

Bem-vindo ao manual do usuário do **AxTon**, o sistema de gestão de pesagem veicular da Axion Tecnologia.

## O que é o AxTon?

O AxTon é uma plataforma destinada ao **controle e monitoramento de pesagem de veículos**, integrando postos de pesagem, classificação de veículos e geração de registros de infração por excesso de peso. O sistema abrange as seguintes etapas:

- **Cadastro de locais** — registro dos postos e pontos de pesagem
- **Classificação de veículos** — categorização dos tipos de veículos fiscalizados
- **Controle de sequencial de infração** — numeração e rastreabilidade dos registros de infração
- **Gestão de usuários** — controle de acesso e permissões por perfil
- **Configuração de permissões** — definição de quais funcionalidades cada perfil pode acessar

## Como utilizar este manual

Utilize o **menu lateral** para navegar entre os módulos do sistema. Cada seção contém:

- **Descrição da funcionalidade** — o que a tela realiza e quando deve ser utilizada
- **Campos** — tabela descritiva de cada campo do formulário
- **Passo a passo** — sequência de ações para executar a operação
- **Alertas e observações** — informações importantes sobre restrições ou cuidados necessários

## Requisitos de acesso

O acesso ao AxTon requer:

1. Credenciais de usuário (nome de usuário e senha) fornecidas pelo administrador do sistema
2. Navegador atualizado (Google Chrome, Mozilla Firefox ou Microsoft Edge)
3. Conexão com a rede onde o sistema está hospedado

:::info Suporte
Em caso de dúvidas ou problemas, entre em contato com o administrador do sistema da sua organização ou com o suporte da Axion Tecnologia.
:::
