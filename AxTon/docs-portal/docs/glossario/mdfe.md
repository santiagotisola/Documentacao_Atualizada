# MDF-e (Manifesto de Documento Fiscal)

![Exportação de Infrações](../img/Exportacao%20de%20infracoes.png)

Documento eletrônico que vincula as notas fiscais ao transporte. Veículos de carga devem portar MDF-e válido. A ausência gera alerta no sistema.

**Base legal:** Ajuste SINIEF 21/2010
