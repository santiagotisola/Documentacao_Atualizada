# NFe (Nota Fiscal Eletrônica)

![Exportação de Infrações](../img/Exportacao%20de%20infracoes.png)

Documento fiscal digital que acompanha o transporte de mercadorias. O AxTon captura automaticamente as chaves NFe dos veículos em trânsito para rastreabilidade fiscal.

**Base legal:** Ajuste SINIEF 07/2005
