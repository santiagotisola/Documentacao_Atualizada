# Configurações do Sistema

![Tela de Configurações do Sistema](../img/Sistema.-%20geral.%20png.png)

A tela de **Configurações do Sistema** centraliza os parâmetros fundamentais do AxTon. Ela é dividida em abas que organizam diferentes aspectos da configuração.

## Como acessar

**Menu lateral** → Sistema → **Configurações do Sistema**

![Configuração - Dados do Órgão](../img/Sistema%20-%20dados%20do%20orgao.png)

## Abas disponíveis

| Aba | Descrição |
|-----|-----------|
| **Gerais** | Parâmetros gerais de funcionamento do sistema |
| **Dados do Órgão** | Informações do órgão fiscalizador responsável |
| **HAENNI** | Configurações para integração com balança HAENNI |
| **Infração** | Parâmetros para geração e processamento de infrações |
| **Câmera IP** | Configuração de câmera IP para captura de imagens |
