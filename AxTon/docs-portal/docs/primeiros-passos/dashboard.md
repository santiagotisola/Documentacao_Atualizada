# Painel Principal

O Painel Principal é a tela inicial do AxTon após a autenticação. Apresenta um resumo do estado operacional do sistema, incluindo indicadores de pesagem e acesso rápido aos módulos disponíveis.

![Painel Principal](../img/dashboard.png)

## Como acessar

Ao realizar o login, o sistema redirecionará automaticamente para o Painel Principal. Também é possível acessá-lo pelo **Menu lateral** → primeiro ícone (Dashboard).

## Elementos da tela

### Menu lateral

O menu lateral exibe todos os módulos disponíveis para o perfil de acesso do usuário autenticado. Os itens são exibidos de forma hierárquica, permitindo expandir e recolher as categorias.

### Indicadores gerais

O painel apresenta indicadores resumidos com dados atualizados sobre as operações de pesagem registradas no sistema.
