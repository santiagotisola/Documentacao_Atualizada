# Falhas de Sequenciais

![Sequencial de Exportação](../img/sequencial%20de%20exportacao.png)

Identifica lacunas ou duplicações na numeração sequencial de Infrações garantindo a integridade dos registros.

## Como acessar

**Menu lateral** → Relatórios → **Falhas de Sequenciais**

## Dados do Relatório

### Colunas

| Coluna | Descrição |
|--------|-----------|
| **Sequencial** | Número esperado |
| **Status** | Presente ou Ausente |
| **Data** | Data esperada |
| **Observação** | Detalhes da falha |

### Filtros disponíveis

- Período (data inicial e final)
- Posto de pesagem
- Exportar para Excel/PDF
