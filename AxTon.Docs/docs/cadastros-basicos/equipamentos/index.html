Equipamentos

Cadastro dos equipamentos de pesagem. Estes registros são fundamentais para o funcionamento do sistema de pesagem.

Como acessar​

Menu lateral → Cadastros Básicos → Equipamentos

Listagem​

Colunas​

ColunaDescrição
CódigoIdentificador único
NomeNome do equipamentos
AtivoStatus do registro

Passo a passo — Cadastrar​

  1. Acesse Cadastros Básicos → Equipamentos
  2. Clique em + Novo
  3. Preencha os campos obrigatórios
  4. Clique em Salvar
Dependência

Para cadastrar um equipamento, é necessário ter previamente cadastrado: Fabricante, Tipo e Modelo.
