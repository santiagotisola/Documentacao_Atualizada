## 📡 API ENDPOINTS (Principais)

### **Orchestrator**
```
POST /api/orchestrator/execute      - Executa qualquer modo autônomo
POST /api/orchestrator/discover     - Discovery autônomo
POST /api/orchestrator/validate     - Validação completa
POST /api/orchestrator/regression   - Suite de regressão
GET  /api/orchestrator/modes        - Lista modos disponíveis
GET  /api/orchestrator/status       - Histórico de execuções
```

### **CUTI**
```
POST /api/cuti/execute              - Executa validação via CUTI
POST /api/cuti/learn                - Inicia gravação de cenário
POST /api/cuti/stop                 - Para gravação
GET  /api/cuti/scenarios            - Lista cenários gravados
```

### **Scenarios**
```
GET  /api/scenarios                 - Lista todos os cenários
GET  /api/scenarios/:id             - Busca cenário por ID
POST /api/scenarios/:id/execute     - Executa cenário específico
POST /api/scenarios/bulk            - Executa múltiplos cenários
```
